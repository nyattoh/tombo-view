目的: 個人用ローカル資料検索ツールにおける索引読み込み方針（起動時読み込み eager vs 初回検索時読み込み lazy）の決定

## 証拠で確かめたこと

- eager案（起動1.6秒・初回検索0.05秒・メモリ90MB）とlazy案（起動0.3秒・初回検索1.4秒・メモリ90MB）はいずれも必須条件（起動2秒以内・初回検索2秒以内・最大メモリ120MB以内）を満たしている (支持)。範囲: local\_search\_tool
- 起動の待ち時間と初回検索の待ち時間のどちらを重視するかは未定である (支持)。範囲: local\_search\_tool
- 利用者は初回検索の速さよりも起動の待ち時間短縮を重視する (反証)。範囲: local\_search\_tool
- 利用者の優先順位に応じて、起動待ち時間短縮を重視するならlazy案、初回検索の即応性を重視するならeager案を選択する (支持)。範囲: local\_search\_tool
- 利用者は初回検索の待ち時間短縮（即応性）を優先すると明答した (支持)。範囲: local\_search\_tool
- 初回検索の待ち時間短縮を優先する利用者の意向に基づき、eager案（起動時に索引読み込み）を採用する (支持)。範囲: local\_search\_tool
