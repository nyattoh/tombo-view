# 会議向け提案理由の再検討と説明文（当日の運用事情反映版）

## 1. 「土曜という曜日を理由にする」点はそのままでよいか

**結論：そのままでの理由づけは推奨できません（見直しが必要です）。**

### 新たに判明した運用事実（`exhibit/operations.txt`）
1. **9月5日・12日（土曜）**：
   - 同じ建物内で別の無料イベントが開催されており、展示入口をその受付と共用していた。
   - 来場者が展示目当てか別イベント目当てかは記録されていない（別イベントからの流入・立ち寄りが生じていた可能性が高い）。
2. **9月20日（日曜）**：
   - 別のイベントは開催されていなかった。
   - 展示入口の案内板を設置し忘れていた（単独開催かつ誘導が不足していた）。
3. **次回開催の見通し**：
   - 部屋は土日どちらも利用可能。
   - 別のイベントが開催されるかどうかは現時点で不明。

### なぜそのままで理由づけしてはならないか
- 前回の土曜（32人・35人）と日曜（18人）の来場者数の差は、「曜日自体の集客力」によるものではなく、**「併催イベントの有無」「入口受付の共用」「案内板設置の有無」という運用条件の違いが大きく影響（交絡）していた**ことが確認されました。
- 次回に別イベントが併催されるか不明な状況で、「土曜のほうが人が多いから」と曜日のみを理由に決定すると、同等の集客が得られないリスクがあり、会議での説得力も損なわれます。

## 2. 会議で話す短い文（再作成案）

> 「前回の実績では土曜が30人台、日曜が18人でしたが、受付記録を確認したところ、土曜は建物内の別イベントと受付入口を共用していた一方、日曜は単独開催かつ案内板の設置漏れがあったことがわかりました。
> そのため前回の差は曜日というより併催イベント等の影響が大きかったと考えられます。次回は土日いずれも部屋が使えるため、併催イベントの有無や案内表示の徹底を前提に、どちらの日程がよいかご相談させてください。」
