## 証拠で確かめたこと

- Cedar RoomとHarbour Roomはどちらも12名収容可能で希望日に利用可能である (支持)。範囲: workshop room options
- Cedar Roomは駅から徒歩10分、50,000円、静かだがホワイトボードはない (支持)。範囲: workshop room options
- Harbour Roomは駅から徒歩25分、30,000円、ホワイトボード付きだが適度な街頭騒音がある (支持)。範囲: workshop room options
- どちらの部屋を押さえるべきかはホワイトボードの要否、予算、徒歩距離、騒音許容度の優先順位に依存する (支持)。範囲: workshop room options
