Status: all 19 model trial turns across 11 raw scenarios are terminal; fresh final review is NEEDS_REVIEW, with acceptance2 unmet in the latest continuity trial. Parent decision pending. ## Method and boundaries

Fresh Google/Antigravity children used the actual skill plus raw task requests/local materials. They were not given the charter, author rationale, expected answer/action, prior findings or future-stage messages. The exact generic operational brief is observer-brief.txt. Raw scenarios and staged delivery manifests are under forward-raw/. PM released each follow-up only after the preceding turn became terminal and archived artifacts before replacement. B04 stage3 used a fresh child with no conversation history and only the same permitted saved workspace. Shared runtime/product files were read-only; each observer could write only its own .session folder. Freeze hashes identify the tested skill versions.

The agent's own proposals/assessments are not ground truth. PM compared actual responses, input files, observations, state, journal and reports. Source/statement validity and semantic assessment quality are distinct. Model costs and tokens were not measured and remain unknown. Helper additional LLM API calls were zero. Tool accounting is host-declared, not an independently metered model cost record. Synthetic files contain no real personal data or secrets.

Supplying the skill to an observer tests its execution, including raw requests without an explicit skill name; it does not demonstrate autonomous host discovery. Discovery is supported by the frontmatter/UI and unchanged default implicit policy, and depends on the host. No global skill installation, resident hook, message interception or named-provider dependency was added.

## Practical limits

The skill prepares real inputs and executes evidence checks, ask, proceed, reconsider and resume through the helper in observed cases, including complete same-task human-answer and fresh-conversation resumption examples. It cannot guarantee good semantic assessments, discovery of every blind spot, causal validity, host auto-selection or uninterrupted continuation beyond finite budgets. Failed proposals, timeouts and model mistakes remain visible. The D01 same-goal task-transition failure remains a material observed limitation after the second correction. A different task or budget must never be presented as unbroken continuation of a previous bounded run. Parent final acceptance and publication are pending; no blanket behavioural pass is claimed.
