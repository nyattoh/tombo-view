# Independent forward-test plan

PM-owned assessment plan, 2026-10-20. These are planned checks, not observed successes. Actual revised skill must be frozen before dispatch. Give each fresh observer only the skill location, raw request/artifacts and operational permissions; do not give this plan, design, charter, expected answers or prior observer output. Observer results and generated state/report artifacts are saved separately by PM. No direct model API calls; authorised T3 child tasks only. No named-provider dependency for end users. Costs/tokens unknown.

Use two independent observers with disjoint scratch folders under results/understanding-forward/. Each should actually perform tasks through the helper, write its own inputs and retain generated state, observations, proposal envelopes, commands, exit codes and reports. Scratch is ignored; PM records hashes and concise observed evidence in this directory. Give follow-up messages as additional raw user turns in the scenario, without naming the intended action. No shared product writes.

Coverage to assess after execution: development external check, adequate-evidence proceed without needless ask, human-only priority/permission and actual reply, failed necessary verification, counterexample and reframing, correction alongside genuine contradictory evidence, scope mismatch, follow-up understanding updates, save/replay/resume boundaries. Explicit invocation and non-explicit selection should be distinguished: supplying a skill for a trial tests its use, not autonomous host discovery. Do not claim interception of every message. Discovery metadata/implicit policy is inspected independently; actual host-autoselection remains unverified unless directly observed.

Observer outputs must be judged against actual user task success and preserved evidence, not wording or self-reported confidence. Mechanism tests and fixed synthetic role-play do not establish general live efficacy. On failure, retain the failed run, make only evidence-supported fixes under assigned ownership and use new raw scenarios for re-evaluation. Maximum two full-review fix/review rounds; no passing by lowering the charter.
