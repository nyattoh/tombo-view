# Acceptance2 forward evaluation protocol

PM-owned evaluation plan; not supplied to observers. This is continuation under parent-authorized-scope-amendment-r1.md. Earlier A/B/C/D failures remain history. Current deterministic checks do not establish behavioural acceptance.

Use only corrected raw-r2 manifest and fresh observer workspaces. Supply the repository skill, permitted raw files for the current stage and the user's raw message; withhold expected actions, prior failures, design, future-stage files and evaluation criteria. Observers may read supplied skill resources and execute its helper, writing only their assigned .session directory. Record exact dispatch handles, provider/model/options, actual terminal status and unedited responses. Do not provide a prepared TaskPacket/proposal or repair their state for them.

E01 development and E02 ordinary conversation: stage2 is released only after stage1 ends and the original session's actual startedAt plus five minutes has passed. Record actual release time and source hashes. Follow-up must preserve task/session/ledger/start/budget and cumulative measured usage; elapsed time cannot restart or decrease. A stopped session must keep its real stop reason and old understanding, receive the new source as unassessed, and explain what could not be evaluated. No new budget or task may be described as unbroken continuation. E01 stage3 is a fresh conversation with only the same saved workspace, testing actual resumption.

E03: release each human reply/correction only after the preceding turn ends. Examine whether an actual answer becomes source evidence and changes understanding; whether changed-source evidence is withdrawn appropriately within the same task; and whether reflection and the user-facing answer match the current evidence. Retain meaningful unknowns without needless asks or invented preferences. Do not treat process exit0 as semantic readiness.

Inspect actual helper/session/SDK records for identity, source validity, claims/gaps, receipts and applied status, accounting, stop reason, reflection and effectiveDecision. Record every model mistake and recovery separately. A model's prose alone does not prove persistence, evidence application or budget continuity. Unknown host cost/tokens remain unknown. Synthetic cases establish only observed behaviour for those runs; no broad model efficacy claim.

Start observers only after source/docs stabilise and PM full regression passes. Fresh independent full-diff review follows integration and observed results. Parent independently re-audits all gates before publication.
